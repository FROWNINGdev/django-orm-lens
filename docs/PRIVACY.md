# Privacy Policy

**Last updated:** 2026-07-13

## Scope

This document describes the privacy practices of the **FROWNINGdev** developer
tools, including the `django-orm-lens` open-source project and any personal
automation apps registered by the maintainer (`FROWNINGdev`) on third-party
platforms (LinkedIn, GitHub, PyPI, and similar).

## What we collect

**Nothing from third parties.**

- The `django-orm-lens` VS Code extension, Python CLI, and MCP server operate
  entirely on the user's local machine. They read `models.py` files from the
  user's own workspace, produce static analysis output, and never make network
  calls or send telemetry.
- Any developer apps registered by `FROWNINGdev` on external platforms
  (e.g. LinkedIn) are personal automation tools that interact only with the
  maintainer's own account. They do not collect, store, process, or transmit
  personal data belonging to any third party.

## What we store

**Nothing that leaves the user's machine.**

- No account creation, no analytics, no crash reporting, no usage tracking.
- OAuth tokens issued by third-party platforms (LinkedIn, GitHub) for the
  maintainer's personal automation are stored only in a local keystore on the
  maintainer's own machine and are never shared, transmitted, or exposed.

## Third parties

We do not sell, rent, share, or otherwise disclose any information to third
parties, because we do not collect any.

## Data retention

There is no data to retain. Local files created by the software (e.g. cached
parser output) live on the user's own machine and can be deleted at any time
by removing the extension, uninstalling the package, or clearing the workspace.

## Children's privacy

The software is not directed at children under 13 and does not knowingly
collect information from anyone.

## Changes

If this policy changes, the revision date at the top of this document will be
updated. History is available in the project's Git log.
