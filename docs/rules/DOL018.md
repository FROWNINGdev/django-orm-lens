# DOL018 — Several ids stored in one column

**Default severity:** warning · **Applicability:** unsafe · **Category:** model

A `CharField`, `TextField`, `JSONField`, or a subclass of one of those, whose name ends in `_ids` (`job_ids`, `interviewer_ids`). The column holds many identifiers that cannot be indexed or constrained as rows.

This is a review hint. A snapshot or a cache may keep the list on purpose. Silence that column with `# orm-synapse-disable-next-line DOL018`.

A scalar `company_id = IntegerField()` is not this rule. That shape has no foreign key to copy, and many projects use it on purpose.

## Bad

```python
class Lead(models.Model):
    job_ids = models.TextField(default="")
```

## Good

```python
class LeadJob(models.Model):
    lead = models.ForeignKey(Lead, on_delete=models.CASCADE)
    job_id = models.PositiveIntegerField()
```
