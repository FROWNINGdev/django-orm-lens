# DOL019 — Repeated column group

**Default severity:** warning · **Applicability:** unsafe · **Category:** model

Three or more columns that share a stem and a numeric suffix: `phone_1`, `phone_2`, `phone_3`. Two columns are not reported. A name without the underscore, such as `iso8601`, is not a group.

This is a review hint. A fixed, ordered set of values can stay as columns. Silence the first column of the group with `# db-synapse-disable-next-line DOL019`.

## Bad

```python
class Contact(models.Model):
    phone_1 = models.CharField(max_length=20)
    phone_2 = models.CharField(max_length=20)
    phone_3 = models.CharField(max_length=20)
```

## Good

```python
class ContactPhone(models.Model):
    contact = models.ForeignKey(Contact, on_delete=models.CASCADE)
    number = models.CharField(max_length=20)
```
