# DOL012 — Model without __str__ method

**Default severity:** info · **Applicability:** suggestion · **Category:** model

Detects a class inheriting from `models.Model` whose body defines no `__str__` method (abstract models with `abstract = True` in `Meta` are skipped). Without `__str__`, admin changelists, `ForeignKey` dropdowns, shell reprs, and `{{ obj }}` in templates all render as `ModelName object (1)` — useless for humans and for debugging. There is no QuickFix: generating a meaningful body requires choosing which field to render, which only you can do.

## Bad

```python
class Article(models.Model):
    title = models.CharField(max_length=255)
```

## Good

```python
class Article(models.Model):
    title = models.CharField(max_length=255)

    def __str__(self) -> str:
        return self.title
```

## Suppress

```python
# django-orm-lens-disable-next-line DOL012
```

Or per-workspace in `.vscode/settings.json`: `{"djangoOrmLens.rules": {"DOL012": "off"}}`.
