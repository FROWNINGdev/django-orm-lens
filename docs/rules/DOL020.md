# DOL020 — Column copies an attribute of a related row

**Default severity:** warning · **Applicability:** unsafe · **Category:** model

A scalar column named `{relation}_{suffix}` beside a `ForeignKey` or `OneToOneField` named `{relation}`. The suffix is one of `name`, `title`, `email`, `slug`, `code`, `label`, `phone`, `address`. Example: `company` plus `company_name`.

The copied value goes stale when the related row changes, unless this table is meant to keep a snapshot. Silence a snapshot with `# db-synapse-disable-next-line DOL020`.

`company_id = IntegerField()` with no `company` foreign key is not this rule.

## Bad

```python
class Order(models.Model):
    company = models.ForeignKey(Company, on_delete=models.CASCADE)
    company_name = models.CharField(max_length=100)
```

## Good

```python
class Order(models.Model):
    company = models.ForeignKey(Company, on_delete=models.CASCADE)
```
