# DOL016 — Meta index or constraint without a name

**Default severity:** error · **Applicability:** unsafe · **Category:** model

Inside `class Meta`, every index and uniqueness declaration must carry an explicit name.

`index_together` and `unique_together` cannot name their entries at all, so any use is reported. Replace them with `indexes` / `constraints`. `models.Index` (and postgres `*Index` subclasses), `UniqueConstraint`, and `CheckConstraint` are reported when the call has no top-level `name=`. A `name=` buried inside `Q(...)` or another nested call does not count.

There is no QuickFix: the name has to be chosen, and it has to stay unique within the database's index-name limits.

## Bad

```python
class Event(models.Model):
    class Meta:
        index_together = [
            ("company_id", "is_campus_event", "status"),
            ("company_id", "end_dt"),
        ]
        unique_together = [("company_id", "status")]
        indexes = [
            models.Index(fields=["company_id", "status"]),
        ]
```

## Good

```python
class Event(models.Model):
    class Meta:
        indexes = [
            models.Index(
                fields=["company_id", "is_campus_event", "status"],
                name="idx_company_campus_status",
            ),
            models.Index(fields=["company_id", "end_dt"], name="idx_company_end"),
            models.Index(fields=["company_id", "status"], name="idx_company_status"),
        ]
        constraints = [
            models.UniqueConstraint(
                fields=["company_id", "status"],
                name="uniq_company_status",
            ),
        ]
```

## Suppress

```python
# orm-synapse-disable-next-line DOL016
```

Or per-workspace in `.vscode/settings.json`: `{"ormSynapse.rules": {"DOL016": "off"}}`.
