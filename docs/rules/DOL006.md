# DOL006 — Drop list() around a QuerySet in for-loop

**Default severity:** info · **Applicability:** safe · **Category:** queryset

Detects `for x in list(qs):` where `qs` is a queryset-shaped expression. Wrapping the queryset in `list()` forces immediate full evaluation and builds a second in-memory copy of every row before the first loop iteration runs. QuerySets are already iterable — dropping the wrapper avoids the extra list and composes with `.iterator()` chunked streaming for large result sets. The QuickFix ("Drop list() and iterate directly") removes only the `list(...)` wrapper and is safe to auto-apply.

## Bad

```python
for user in list(User.objects.filter(is_active=True)):
    send_digest(user)
```

## Good

```python
for user in User.objects.filter(is_active=True):
    send_digest(user)
```

## Suppress

```python
# django-orm-lens-disable-next-line DOL006
```

Only call `list()` deliberately — e.g. to snapshot results before mutating rows inside the loop; suppress the finding in that case. Or per-workspace in `.vscode/settings.json`: `{"djangoOrmLens.rules": {"DOL006": "off"}}`.
